    Comandos de Linux — Chuleta

    Referencia rápida de los comandos de terminal que más se usan. Sin teoría: el comando, sus opciones habituales y lo que suele fallar.

    Moverse y listar

    pwd                 # en qué carpeta estás
ls                  # listar el contenido
ls -l               # formato largo (permisos, propietario, tamaño, fecha)
ls -a               # incluir los archivos ocultos (empiezan por .)
ls -lh              # formato largo con tamaños legibles (K, M, G)
ls -R               # listar también las subcarpetas
cd carpeta          # entrar en una carpeta
cd ..               # subir un nivel

    Crear, copiar, mover y borrar

    mkdir proyecto              # crear una carpeta
mkdir -p a/b/c              # crear también las carpetas intermedias que falten
touch notas.txt             # crear un archivo vacío

cp origen.txt copia.txt     # copiar un archivo
cp -r carpeta copia/        # copiar una carpeta con todo su contenido
mv notas.txt viejo.txt      # renombrar
mv notas.txt carpeta/       # mover a una carpeta

rm notas.txt                # borrar un archivo
rm -r carpeta               # borrar una carpeta y su contenido
    • rm no borra carpetas por defecto: hace falta -r. Con -f ignora los archivos que no existen y nunca pregunta.
    • rm borra directamente, sin papelera. Comprueba la ruta antes de ejecutarlo.

    Ver el contenido de un archivo

    cat archivo.txt             # mostrarlo entero
head archivo.txt            # primeras 10 líneas
tail archivo.txt            # últimas 10 líneas
tail -n 50 archivo.txt      # últimas 50 líneas
tail -f registro.log        # seguir el archivo mientras crece (logs)

    Buscar

    find . -name "*.txt"            # archivos cuyo nombre encaja con el patrón
find . -type f -name "*.log"    # solo archivos (d = carpetas)

grep "error" registro.log       # líneas que contienen "error"
grep -i "error" registro.log    # sin distinguir mayúsculas
grep -n "error" registro.log    # con el número de línea
grep -v "error" registro.log    # las líneas que NO lo contienen
grep -c "error" registro.log    # cuántas líneas lo contienen
grep -r "error" carpeta/        # buscar en todos los archivos de una carpeta
    • find busca por nombre o tipo de archivo; grep busca dentro de los archivos.

    Permisos y propietarios

    Cada archivo tiene permisos para tres grupos: el propietario, el grupo y otros. En chmod numérico, cada permiso vale un número: 4 lectura, 2 escritura, 1 ejecución. Se suman y se escribe una cifra por grupo.

    NúmeroPermisosCálculo
    7Leer, escribir y ejecutar4 + 2 + 1
    6Leer y escribir4 + 2
    5Leer y ejecutar4 + 1
    4Solo leer4
    0Ninguno—
     
    chmod 755 script.sh          # propietario 7, grupo 5, otros 5
chmod 644 notas.txt          # propietario 6, grupo 4, otros 4
chown ana archivo.txt        # cambiar el propietario
chown ana:grupo archivo.txt  # cambiar propietario y grupo
chown -R ana carpeta/        # aplicarlo también al contenido

    Procesos

    ps aux              # todos los procesos, con formato orientado al usuario
ps -ef              # todos los procesos, con formato completo
kill 1234           # pedir al proceso 1234 que termine (señal TERM)
kill -9 1234        # forzar su cierre (señal KILL)

    kill envía por defecto la señal TERM, que permite al proceso limpiar antes de cerrarse. La señal KILL (-9) no puede ser interceptada y no da esa oportunidad: úsala solo si TERM no funciona.

    Redirecciones y tuberías

    ls -l > lista.txt              # guardar la salida en un archivo (sobrescribe)
ls -l >> lista.txt             # añadirla al final del archivo
comando 2> errores.txt         # guardar solo los mensajes de error
ls -l | grep "txt"             # la salida del primer comando pasa al segundo
cat registro.log | grep -c "error"

    La tubería | conecta la salida estándar de un comando con la entrada estándar del siguiente: permite encadenar herramientas simples.

    Espacio en disco

    df -h               # espacio usado y libre por sistema de archivos, en formato legible

    Errores frecuentes

    • rm -rf con una ruta equivocada. Borra sin preguntar y sin papelera. Revisa la ruta y usa ls antes.
    • > en lugar de >>. > sobrescribe el archivo; >> añade al final.
    • Abusar de chmod 777. Da permisos totales a todo el mundo. Da solo los permisos necesarios.
    • Nombres con espacios. Ponlos entre comillas ("mi archivo.txt") o el terminal los tratará como dos argumentos.
    • Usar kill -9 como primer intento. Prueba antes con kill a secas.
