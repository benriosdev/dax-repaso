    Definición

    A

    Abstracción (Programación A)
    Quedarse solo con los detalles esenciales de un problema, ignorando lo que no es relevante para resolverlo. Ver más →
    Agile / Metodologías ágiles (Entornos de Desarrollo, Vocabulary)
    Forma de gestionar proyectos mediante iteraciones cortas y entregas frecuentes, en vez de cerrar cada fase antes de pasar a la siguiente. Ver más →
    Algoritmo (Programación A)
    Secuencia finita y ordenada de pasos que resuelve un problema concreto. Ver más →
    API (Vocabulary, Lenguaje de Marcas)
    Conjunto de reglas que permite que dos aplicaciones se comuniquen entre sí. Ver más →
    ASG (Sostenibilidad)
    Criterios Ambientales, Sociales y de Gobernanza usados para medir el impacto y la responsabilidad de una empresa. Ver más →

    B

    Backend / Frontend (Vocabulary, Lenguaje de Marcas)
    La lógica y datos del servidor frente a lo que ve y usa la persona en el navegador. Ver más →
    Big Data (Bases de Datos A, Digitalización)
    Volúmenes de datos tan grandes o variados que superan la capacidad de los SGBD tradicionales. Ver más →
    Bug (Programación A)
    Error o comportamiento inesperado en el código que impide que un programa funcione como se espera. Ver más →

    C

    Casting (Programación A)
    Conversión de un valor de un tipo de dato a otro, implícita o explícita. Ver más →
    Clase / Objeto (Programación A)
    La clase es la plantilla (atributos + métodos); el objeto es cada instancia concreta creada a partir de ella. Ver más →
    Cloud / Edge computing (Digitalización)
    Usar servidores remotos por internet frente a procesar los datos cerca de donde se generan. Ver más →
    CRUD (Programación B)
    Las cuatro operaciones básicas sobre datos: Create, Read, Update, Delete. Ver más →
    CSS (Lenguaje de Marcas)
    Lenguaje que define la presentación visual de un documento HTML. Ver más →

    D

    DOM (Lenguaje de Marcas)
    Representación en memoria de una página web como un árbol de objetos, manipulable con JavaScript. Ver más →

    E

    Encapsulación (Programación A)
    Ocultar los detalles internos de una clase y exponer solo lo necesario mediante métodos públicos. Ver más →
    ERP / CRM (Lenguaje de Marcas)
    Sistema que integra los procesos de una empresa (ERP) o que gestiona la relación con clientes (CRM). Ver más →
    Excepción (Programación A)
    Evento inesperado que interrumpe el flujo normal de un programa y que se gestiona con try/catch/finally. Ver más →

    F

    Framework (Vocabulary)
    Conjunto de herramientas y convenciones reutilizables sobre las que se construye una aplicación. Ver más →

    G

    GDPR / RGPD (Vocabulary, Bases de Datos A)
    Normativa europea de protección de datos personales. Ver más →

    H

    Herencia (Programación B)
    Mecanismo por el que una clase reutiliza atributos y métodos de otra mediante extends. Ver más →
    HTML (Lenguaje de Marcas)
    Lenguaje de marcas específico para construir la estructura de páginas web. Ver más →

    I

    IDE (Entornos de Desarrollo)
    Entorno de desarrollo integrado: editor, compilador, depurador y control de versiones en una sola herramienta. Ver más →
    IoT / TDH (Digitalización)
    Tecnologías Habilitadoras Digitales: IoT, big data, IA, robótica... que hacen posible la transformación digital. Ver más →

    J

    JavaScript (Lenguaje de Marcas)
    Lenguaje que añade interactividad a una página web, ejecutándose en el navegador. Ver más →
    JDBC (Programación B)
    API estándar de Java para conectar una aplicación con distintos motores de bases de datos. Ver más →

    M

    Modelo Entidad-Relación (Bases de Datos A, Anexo E-R)
    Herramienta de diseño conceptual con entidades, atributos y relaciones, previa al diseño de las tablas. Ver más →
    MongoDB / NoSQL (Bases de Datos B)
    Bases de datos no relacionales que abandonan el modelo de tablas fijas, como las documentales de MongoDB. Ver más →

    N

    Normalización (Bases de Datos A)
    Proceso que reorganiza las tablas de una base de datos para eliminar redundancias e inconsistencias. Ver más →

    O

    ODS (Sostenibilidad)
    Los 17 Objetivos de Desarrollo Sostenible de la Agenda 2030 de Naciones Unidas. Ver más →

    P

    Pila / Cola (Programación B)
    Estructuras de datos LIFO (última en entrar, primera en salir) y FIFO (primera en entrar, primera en salir). Ver más →
    PL/SQL (Bases de Datos B)
    Extensión de SQL con estructuras de control propias de un lenguaje de programación, usada dentro de la base de datos. Ver más →
    Polimorfismo (Programación B)
    Una misma referencia de tipo superclase se comporta de forma distinta según el objeto real que contenga. Ver más →
    PRL (IPE I)
    Prevención de Riesgos Laborales: normativa y prácticas para evitar daños a la salud en el trabajo. Ver más →
    Pseudocódigo (Programación A)
    Descripción de un algoritmo en lenguaje natural mezclado con estructuras de control, sin sintaxis de un lenguaje concreto. Ver más →

    R

    Recursividad (Programación A)
    Técnica en la que una función se llama a sí misma para resolver versiones más pequeñas del mismo problema. Ver más →
    Refactorización (Entornos de Desarrollo)
    Reorganizar código existente para mejorar su estructura sin cambiar su comportamiento externo. Ver más →

    S

    Scrum / Kanban (Vocabulary)
    Frameworks ágiles concretos, centrados en iteraciones cortas y en la entrega continua respectivamente. Ver más →
    Sistema operativo (Sistemas Informáticos)
    Software que gestiona el hardware y ofrece una interfaz para ejecutar programas. Ver más →
    SQL (Bases de Datos A)
    Lenguaje estándar para consultar y manipular bases de datos relacionales (DDL, DML, DCL). Ver más →
    Stakeholder (Sostenibilidad)
    Cualquier parte afectada por la actividad de una empresa: empleados, clientes, proveedores, comunidad. Ver más →

    T

    TCP/IP (Sistemas Informáticos)
    Protocolo base de las comunicaciones en internet y redes locales. Ver más →
    Test unitario (Programación A)
    Prueba automatizada que verifica que una función o método concreto funciona como se espera. Ver más →
    Transacción (Bases de Datos B)
    Conjunto de operaciones que se ejecutan como una unidad indivisible (propiedades ACID). Ver más →

    U

    UML (Entornos de Desarrollo)
    Lenguaje gráfico estándar para representar el diseño de un sistema software. Ver más →

    V

    Variable (Programación A, Fundamentos de Java)
    Espacio de almacenamiento con nombre, tipo y valor que puede cambiar durante la ejecución de un programa. Ver más →
    Virtualización (Sistemas Informáticos)
    Ejecutar uno o varios sistemas operativos "invitados" aislados dentro de una máquina física. Ver más →

    X

    XML (Lenguaje de Marcas, Anexo E-R)
    Lenguaje de marcas genérico que permite crear etiquetas propias para describir cualquier tipo de información. Ver más →
