    Sintaxis de Java — Chuleta

    Referencia rápida de la sintaxis y las clases de Java que más se usan. Sin teoría: solo la forma de escribirlo y lo que suele fallar.

    Estructura de un programa

    public class Main {
    public static void main(String[] args) {
        System.out.println("Hola Mundo");
    }
}

    El archivo se llama igual que la clase pública (Main.java). javac lo compila a bytecode y java Main lo ejecuta.

    Operadores

    • Aritméticos: + - * / %. Con dos enteros, / devuelve un entero: 7 / 2 es 3.
    • Dividir un entero entre cero lanza ArithmeticException.
    • Comparación: == != < > <= >=. Lógicos: && || !.
    • Incremento: i++, i--, i += 5.

    Control de flujo

    if (nota >= 5) { ... } else if (nota >= 3) { ... } else { ... }

for (int i = 0; i < 10; i++) { ... }       // contador
for (int n : numeros) { ... }                // recorrer array o colección
while (condicion) { ... }                    // 0 o más veces
do { ... } while (condicion);                // al menos una vez

switch (dia) {
    case 1:  System.out.println("Lunes"); break;
    case 2:  System.out.println("Martes"); break;
    default: System.out.println("Otro");
}
    • Sin break, un switch sigue ejecutando los case siguientes (fall-through).
    • El switch admite byte, short, char, int, enumerados y String. Si la expresión es null, lanza NullPointerException.

    Arrays y colecciones

    int[] notas = new int[3];              // tamaño fijo; índices 0..2
int[] pares = {2, 4, 6};
notas.length                           // 3 (sin paréntesis)

ArrayList<String> lista = new ArrayList<>();
lista.add("Ana");                      // añadir al final
lista.get(0);                          // leer por posición
lista.set(0, "Luis");                  // reemplazar
lista.remove(0);                       // borrar por posición
lista.size();  lista.contains("Ana");  lista.isEmpty();  lista.clear();

HashMap<String, Integer> edades = new HashMap<>();
edades.put("Ana", 30);                 // asociar clave y valor
edades.get("Ana");                     // 30; null si la clave no existe
edades.containsKey("Ana");  edades.remove("Ana");  edades.size();
    • Un array tiene tamaño fijo; un ArrayList crece solo.
    • Un HashMap no garantiza ningún orden y admite clave y valores null.

    Clases, herencia e interfaces

    public class Persona {
    private String nombre;                       // atributo privado

    public Persona(String nombre) {              // constructor: mismo nombre que la clase
        this.nombre = nombre;
    }
    public String getNombre() { return nombre; } // getter
}

public class Alumno extends Persona {            // herencia
    public Alumno(String nombre) {
        super(nombre);                           // llama al constructor del padre
    }
}

public class Coche implements Vehiculo { ... }   // implementa una interfaz

Persona p = new Persona("Ana");                  // crear un objeto

    • Si no escribes ningún constructor, el compilador crea uno sin argumentos.
    • Una clase tiene una sola superclase directa (extends); los constructores no se heredan.
    • Regla práctica: usa el modificador más restrictivo posible, normalmente private.

    Excepciones

    try {
    int x = Integer.parseInt(texto);
} catch (NumberFormatException e) {
    System.out.println("No es un número");
} finally {
    // se ejecuta siempre
}

void leer() throws IOException { ... }   // declara que puede lanzarla

    Las excepciones comprobadas obligan a capturarlas o declararlas con throws. Los Error y las RuntimeException (como NullPointerException o ArithmeticException) no.

    Errores frecuentes

    • Comparar Strings con ==. En objetos, == comprueba si son el mismo objeto, no si tienen el mismo texto. Usa equals().
    • Olvidar el break en un switch. Se ejecutan también los casos siguientes.
    • División entera inesperada. 7 / 2 da 3; para obtener decimales, uno de los operandos debe ser double.
    • Índice fuera de rango. Un array de 3 elementos llega hasta el índice 2; un ArrayList lanza IndexOutOfBoundsException si el índice no existe.
    • Usar double para dinero. Usa BigDecimal.
    • Sobrescribir equals() sin hashCode(). Los dos deben ir juntos.
