    MySQL Workbench

    Herramienta visual oficial de Oracle para diseñar, administrar y consultar bases de datos MySQL, sin depender solo de la línea de comandos.

    0. Qué es y para qué sirve

    MySQL Workbench es la herramienta gráfica oficial y gratuita de Oracle para trabajar con servidores MySQL. Se organiza en tres áreas principales: SQL Development (escribir y ejecutar consultas), Data Modeling (diseñar diagramas entidad-relación) y Server Administration (gestionar usuarios, copias de seguridad y rendimiento del servidor).

    ¿Sabías que...?

    MySQL Workbench es la continuación de DBDesigner 4, una herramienta de modelado que Oracle (a través de su compra de MySQL AB) integró y amplió para cubrir también consultas y administración, no solo diseño.

    1. Conectar con un servidor

    Al abrir Workbench, la pantalla de inicio permite crear una nueva conexión indicando host (por ejemplo localhost o la IP del servidor), puerto (el 3306 por defecto en MySQL), usuario y contraseña. Un botón de "Test Connection" comprueba que los datos son correctos antes de guardar la conexión.

    Varias conexiones

    Es habitual tener guardadas varias conexiones (un servidor local de desarrollo, uno de pruebas, uno de producción); cada una aparece como una tarjeta en la pantalla de inicio, así que cambiar de servidor es tan simple como hacer doble clic en otra tarjeta.

    2. Editor SQL

    El editor SQL es la pestaña donde se escriben y ejecutan las consultas contra la base de datos conectada. Ofrece autocompletado de nombres de tablas y columnas, resaltado de sintaxis y la posibilidad de ejecutar solo la consulta donde está el cursor sin lanzar todo el script.

    SELECT nombre, email FROM usuarios WHERE activo = 1;

    Resultados y exportación

    Cada consulta ejecutada abre una pestaña de resultados en forma de tabla, editable directamente para modificar filas sin escribir un UPDATE. Los resultados se pueden exportar a CSV, JSON o Excel desde el propio panel de resultados.

    3. Modelado entidad-relación (EER)

    El módulo de modelado (EER Diagrams) permite diseñar visualmente las tablas de una base de datos, sus columnas, claves primarias y foráneas, y las relaciones entre ellas, antes de escribir una sola línea de SQL.

    Ingeniería inversa y directa

    La ingeniería inversa (reverse engineering) genera un diagrama automáticamente a partir de una base de datos ya existente, muy útil para entender un proyecto ajeno de un vistazo. La ingeniería directa (forward engineering) hace lo contrario: genera el script SQL con las sentencias CREATE TABLE a partir del diagrama diseñado.

    4. Administración

    Desde el panel de administración se gestionan los usuarios del servidor y sus privilegios (qué bases de datos y qué operaciones puede hacer cada uno), sin necesidad de escribir sentencias GRANT a mano.

    Copias de seguridad y monitorización

    Workbench permite exportar (dump) e importar bases de datos completas o solo algunas tablas, útil para copias de seguridad o para mover datos entre servidores. También ofrece un panel básico de monitorización con el estado de las conexiones activas y el rendimiento del servidor.

    Puntos clave

    • Workbench cubre tres áreas: desarrollo SQL, modelado de datos y administración del servidor.
    • Una conexión se define con host, puerto (3306 por defecto), usuario y contraseña.
    • El editor SQL ejecuta consultas y permite exportar los resultados a CSV, JSON o Excel.
    • La ingeniería inversa genera un diagrama desde una BBDD existente; la directa genera el SQL desde el diagrama.
    • Permite gestionar usuarios y privilegios, y exportar/importar bases de datos completas.

    Ponte a prueba

    ¿Qué tres áreas principales cubre MySQL Workbench?

    SQL Development (consultas), Data Modeling (diagramas entidad-relación) y Server Administration (usuarios, privilegios y rendimiento).

    ¿Qué puerto usa MySQL por defecto al configurar una conexión?

    El puerto 3306.

    ¿Qué diferencia hay entre ingeniería inversa e ingeniería directa en el modelado EER?

    La ingeniería inversa genera un diagrama a partir de una base de datos ya existente; la ingeniería directa genera el script SQL (CREATE TABLE) a partir de un diagrama diseñado.
