    6. Programación orientada a objetos II

    Amplía la POO con los mecanismos que permiten reutilizar y generalizar código entre clases: herencia, polimorfismo y casting entre tipos.

    Métodos y variables estáticas

    Con static, un miembro pertenece a la clase y no a cada objeto: se comparte entre todas las instancias y se puede usar sin crear ningún objeto (Clase.metodo()). Es típico para constantes globales o clases utilitarias.

    Herencia

    Permite que una clase (subclase) reutilice atributos y métodos de otra (superclase) con extends, modelando relaciones jerárquicas (por ejemplo, Perro extends Animal). La palabra clave super permite llamar al método original de la clase base antes de ampliarlo.

    class Animal {
    public void hacerSonido() { System.out.println("Sonido genérico"); }
}
class Perro extends Animal {
    @Override
    public void hacerSonido() { System.out.println("El perro ladra"); }
}

    Interfaces

    Una interfaz define un contrato de métodos que una clase se compromete a implementar, sin imponer una jerarquía de herencia única (una clase puede implementar varias interfaces con implements).

    Métodos y variables abstractas

    Una clase abstract no se puede instanciar directamente y puede declarar métodos sin implementación, obligando a las subclases a definirlos.

    Sobreescritura de métodos y polimorfismo

    Sobreescribir (@Override) significa redefinir en la subclase un método heredado de la superclase. El polimorfismo es la consecuencia directa: una misma referencia de tipo superclase puede comportarse de forma distinta según el objeto real que contenga en tiempo de ejecución.

    Casting entre tipos de referencia

    Igual que con tipos primitivos, un objeto puede convertirse entre su tipo y el de una superclase o interfaz que implemente, siempre dentro de la misma jerarquía de herencia.

    7. Estructuras de datos

    Formas de organizar información en memoria más allá de una simple variable, cada una pensada para un patrón de acceso distinto.

    Arrays y genericidad

    Un array almacena un número fijo de elementos del mismo tipo en posiciones consecutivas. La genericidad (<T>) permite escribir clases y métodos que funcionan con cualquier tipo de dato sin duplicar código, como hace ArrayList<String>.

    Listas enlazadas

    Cada elemento (nodo) guarda su valor y una referencia al siguiente nodo. A diferencia de un array, su tamaño crece dinámicamente y no requiere memoria contigua, aunque el acceso a un elemento concreto es más lento.

    Pilas (stacks)

    Estructura LIFO (Last In, First Out): el último elemento en entrar es el primero en salir. Se usa, por ejemplo, para deshacer acciones o gestionar llamadas recursivas. En Java, la clase Deque se recomienda para implementar una pila en vez de la antigua clase Stack.

    Deque<String> pila = new ArrayDeque<>();
pila.push("A");
pila.push("B");
System.out.println(pila.pop()); // "B" (el último en entrar)

    Colas (queues)

    Estructura FIFO (First In, First Out): el primer elemento en entrar es el primero en salir, como una cola de impresión o de tareas pendientes.

    Queue<String> cola = new LinkedList<>();
cola.offer("A");
cola.offer("B");
System.out.println(cola.poll()); // "A" (el primero en entrar)

    Grafos y otras estructuras

    Un grafo modela nodos (vértices) conectados por aristas, con o sin dirección y con o sin peso, útil para representar redes, rutas o relaciones complejas entre elementos. Una forma sencilla de representarlo en código es una lista de adyacencia: un mapa donde cada nodo guarda la lista de nodos a los que está conectado.

    Map<String, List<String>> grafo = new HashMap<>();
grafo.put("A", List.of("B", "C"));
grafo.put("B", List.of("A"));
// "A" está conectado con "B" y "C"

    Los algoritmos más habituales sobre grafos son el recorrido en anchura (BFS) y en profundidad (DFS), usados por ejemplo para encontrar el camino más corto o comprobar si dos nodos están conectados.

    8. Programación y bases de datos

    Cómo conectar una aplicación Java con distintos motores de bases de datos mediante JDBC (Java Database Connectivity), la API estándar de Java para hablar con un SGBD.

    Conexión a SQLite

    SQLite es un motor de base de datos ligero que no necesita servidor: la base de datos es un único archivo, ideal para aplicaciones pequeñas o de escritorio.

    Conexión a MySQL y PostgreSQL

    Ambos son SGBD cliente-servidor: la aplicación Java se conecta a un servidor de base de datos (local o remoto) mediante una cadena de conexión (URL, usuario y contraseña) y un driver JDBC específico para cada motor.

    Docker

    Docker permite levantar un contenedor con el SGBD ya instalado y configurado (por ejemplo, MySQL o PostgreSQL) sin instalar nada directamente en el sistema operativo, lo que facilita reproducir el mismo entorno en cualquier máquina.

    9. CRUD con bases de datos

    CRUD son las cuatro operaciones básicas sobre datos persistentes: Create (insertar), Read (consultar), Update (actualizar) y Delete (borrar). Este bloque las implementa en Java sobre distintos motores.

    • CRUD con SQLite, MySQL y PostgreSQL usando JDBC y sentencias SQL
    • CRUD con db4o, una base de datos orientada a objetos que guarda directamente objetos Java sin necesidad de mapearlos a tablas
    ¿Sabías que...?

    db4o es una base de datos orientada a objetos: guarda directamente instancias de tus clases Java, sin tener que traducirlas a filas y columnas como en SQL.

    10. Próximos pasos

    Cierre del módulo con Python como puerta de entrada a otro lenguaje. Frente a Java (tipado estático, hay que declarar el tipo de cada variable, y necesita compilarse), Python es de tipado dinámico (el tipo se infiere en tiempo de ejecución) e interpretado (se ejecuta línea a línea, sin paso de compilación), lo que suele traducirse en menos código para la misma tarea a cambio de perder algunas de las comprobaciones que Java hace antes de ejecutar.

    Puntos clave

    • Herencia, polimorfismo e interfaces permiten reutilizar y generalizar comportamiento entre clases.
    • Las estructuras de datos (pilas, colas, listas enlazadas, grafos) se eligen según el patrón de acceso que necesites.
    • JDBC es la API estándar de Java para conectar con SQLite, MySQL o PostgreSQL.
    • CRUD resume las cuatro operaciones básicas sobre datos: Create, Read, Update, Delete.
    • Docker permite levantar un SGBD ya configurado en un contenedor, sin instalar nada en el sistema.

    Ponte a prueba

    ¿Qué diferencia hay entre una pila y una cola?

    La pila es LIFO (el último en entrar es el primero en salir); la cola es FIFO (el primero en entrar es el primero en salir).

    ¿Qué palabra clave usa Java para heredar de otra clase?

    extends.

    ¿Qué significa cada letra de CRUD?

    Create (crear), Read (leer), Update (actualizar), Delete (borrar).

    ¿Qué ventaja tiene usar Docker para levantar una base de datos?

    Tener el mismo entorno reproducible en cualquier máquina, sin instalar el SGBD directamente en el sistema operativo.

    ¿Qué es el polimorfismo?

    Que una misma referencia de tipo superclase se comporte de forma distinta según el objeto real que contenga en tiempo de ejecución.
