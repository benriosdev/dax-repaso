    Vocabulary DAM-DAW-ASIR

    Glosario de vocabulario técnico en inglés para desarrollo de aplicaciones, organizado por bloques temáticos. El documento incluye también, en sus páginas finales, un segundo glosario de terminología 3D/videojuegos que no pertenece al bloque DAM-DAW-ASIR.

    General App Development Terms

    • App: programa diseñado para realizar tareas concretas en ordenador o móvil.
    • Native App: desarrollada específicamente para una plataforma (iOS o Android) con sus lenguajes propios.
    • Cross-Platform App: funciona en varios sistemas operativos compartiendo la mayor parte del código.

    Development Processes and Methodologies

    • Agile Development: metodología iterativa y colaborativa, con respuesta rápida al cambio.
    • Waterfall Model: enfoque secuencial clásico, donde cada fase se cierra antes de empezar la siguiente.
    • Scrum / Kanban: frameworks ágiles concretos, centrados en iteraciones cortas y en la entrega continua respectivamente.
    • Prototyping: crear versiones reducidas de la app para validar ideas antes de desarrollarla entera.

    Programming Languages and Frameworks

    • Swift / Objective-C: lenguajes de Apple para iOS y macOS.
    • Kotlin: lenguaje moderno para Android, alternativa oficial a Java.
    • React Native / Flutter / Xamarin: frameworks para construir apps multiplataforma desde una única base de código (JavaScript, Dart y C# respectivamente).

    App Components and Architecture

    • UI (User Interface) / UX (User Experience): lo visual de la app frente a la calidad de la experiencia global al usarla.
    • Backend / Frontend: la lógica y datos del servidor frente a lo que ve y usa la persona usuaria.
    • API: conjunto de reglas que permite que dos aplicaciones se comuniquen entre sí.

    App Deployment and Distribution

    • App Store: plataforma (Apple App Store, Google Play) donde se publican y descargan apps.
    • Beta Testing / Release Candidate: fases de prueba con usuarios limitados antes del lanzamiento oficial.
    • CI/CD (Continuous Integration/Deployment): automatizar la integración de cambios de código y su despliegue a producción.
    • Version Control: gestión del historial de cambios del código (por ejemplo, con Git).

    App Monetization Strategies

    • Freemium: versión básica gratuita con funciones de pago adicionales.
    • In-App Purchases / Subscription Model: compras puntuales dentro de la app frente a pago recurrente periódico.
    • Ad-Based Revenue: ingresos mediante publicidad dentro de la app.
    ¿Sabías que...?

    La primera tienda de aplicaciones moderna, la Apple App Store, abrió en julio de 2008 con solo 500 apps disponibles. Hoy Google Play y la App Store suman varios millones entre las dos.

    App Analytics and Performance

    • App Analytics: herramientas para medir uso, compromiso y retención de usuarios.
    • Crash Reporting: detección y registro automático de fallos de la app.
    • User Retention / Conversion Rate: porcentaje de usuarios que siguen usando la app, y porcentaje que completa una acción deseada (compra, suscripción...).

    Security and Compliance

    • App Permissions: control de acceso de la app a funciones del dispositivo (cámara, ubicación...).
    • Data Encryption: cifrado de datos para que solo pueda acceder a ellos quien esté autorizado.
    • GDPR / PCI DSS: normativa europea de protección de datos, y estándar de seguridad para el manejo de datos de tarjetas de pago.
    • Two-Factor Authentication (2FA): verificación en dos pasos para acceder a una cuenta.

    Emerging Technologies and Trends

    • AR (Augmented Reality) / VR (Virtual Reality): superponer información digital sobre el mundo real, o sumergir por completo en un entorno digital.
    • Voice-Based Apps: interacción mediante reconocimiento de voz y lenguaje natural.
    • Blockchain-Based Apps: aplicaciones que usan tecnología blockchain para almacenamiento y transacciones descentralizadas.

    Puntos clave

    • Native App se desarrolla para una plataforma concreta; Cross-Platform comparte código entre varias.
    • Agile, Scrum y Kanban son formas de organizar el desarrollo en iteraciones cortas.
    • CI/CD automatiza la integración y el despliegue de cambios de código.
    • GDPR y PCI DSS son normativas de protección de datos y de datos de pago respectivamente.

    Ponte a prueba

    ¿Qué diferencia hay entre una Native App y una Cross-Platform App?

    La nativa se desarrolla específicamente para una plataforma (iOS o Android); la cross-platform comparte la mayor parte del código entre varias plataformas.

    ¿Qué significa CI/CD?

    Continuous Integration / Continuous Deployment: automatizar la integración de cambios de código y su despliegue a producción.

    ¿Para qué sirve la autenticación en dos factores (2FA)?

    Para añadir una segunda verificación además de la contraseña al acceder a una cuenta.
